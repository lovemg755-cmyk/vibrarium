Privacy Policy

Applies to Jarvis Studio, the upload tool of the Vibrarium YouTube channel. Last updated: November 15, 2026.

Who uses this tool

Jarvis Studio is a private tool. It is used only by the owner of the Vibrarium channel to manage that channel. It is not offered to the public, and no other person signs in to it.

What data it accesses

With the owner's permission, through the YouTube Data API, it:

  • reads the basic details of the owner's own channel (name and ID) to confirm the right channel;
  • uploads the channel's own videos, thumbnails and captions;
  • adds those videos to the channel's own playlists.

It does not read viewers' data, comments, subscribers' personal information, email or any other account.

How data is stored

The sign-in token is stored only on the owner's own computer, with file access limited to the owner. Nothing is sent to any server other than Google's. No data is sold, shared with third parties, used for advertising or used to train AI models.

Google API Services

Jarvis Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; by using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer also ends access.

Contact

Questions about this policy can be sent through the Vibrarium channel page: youtube.com/@vibrarium-music.
