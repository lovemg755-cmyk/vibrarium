VIBRARIUM

A VIVARIUM OF VIBES

Vibrarium is a YouTube channel of experimental vibe music from fictional AI artists: late-night electro-pop, viking hip-hop anthems and a new sound every week.

youtube.com/@vibrarium-music

Jarvis Studio (upload tool)

Jarvis Studio is a private tool used only by the owner of the Vibrarium channel. It uses the YouTube Data API to upload the channel's own videos, set their thumbnails and add them to the channel's playlists. It is not offered to the public and does not access anyone else's account.
